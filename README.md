# 🏠 WallColor Paint — BLANLUX SATIN DECO

> **👉 Ouvrir l'application : https://motionmoon-star.github.io/wallcolor-paint/**

Visualiseur de couleurs de murs par IA : photographiez votre pièce, l'IA détecte
les murs et applique les 42 teintes du Nuancier Satinée Color BLANLUX SATIN DECO
— sans toucher aux meubles ni à la décoration.

## Fonctionnalités
- 📸 Photo ou upload, détection IA des murs (100 % dans le navigateur)
- 🎨 Nuancier officiel 42 teintes SATIN DECO
- ✋ Sélection d'un mur au clic, pinceau d'ajout intelligent, gomme, pinceau contour
- 🪶 Affinage du masque : lissage, contour, contraste, décalage (façon Photoshop)
- ⇄ Curseur Avant / Après, export PNG
